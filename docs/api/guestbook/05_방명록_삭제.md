# [Wattagam] 방명록 삭제

상태: 백엔드 구현 완료 (로컬 통합 테스트 통과)
도메인: guestbook
메서드: DELETE
배포 서버 실행 확인: 미확인
엔드포인트: /api/guestbook/{id}
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.3 · 백엔드 구현 완료(로컬 통합 테스트 통과) · 배포 미확인 · Android 연동 미확인.

본인이 작성한 방명록을 삭제합니다. 방명록 행과 OCI에 저장된 이미지를 삭제하며, 이미 지급된 도장은 유지됩니다.

`DELETE /api/guestbook/{id}`

### 연동 시 주의사항

- 삭제해도 도장은 유지됩니다. 도장을 받은 최초 기록이면 `stamps.first_entry_id`가 NULL이 되며(ON DELETE SET NULL), 내 도장판 조회의 firstEntryId가 null로 내려갑니다. 이 외래 키는 방명록 테이블 도입 마이그레이션에서 함께 추가합니다.
- DB 삭제 후 이미지 삭제가 일시 실패해도 응답은 200입니다. 삭제할 키는 방명록 삭제와 같은 트랜잭션에서 `guestbook_image_cleanups`(V6)에 보존되고, 5분마다(`app.guestbook.cleanup.retry-interval`) 성공할 때까지 재시도합니다. (확정 필요: 기본값으로 구현)
- 삭제와 회원 탈퇴는 같은 사용자 행 락을 사용합니다.
- 이미 삭제됐거나 없는 ID는 GUESTBOOK_404_1입니다.
