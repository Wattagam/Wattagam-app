# [Wattagam] 방명록 상세 조회

상태: API 개발 전
도메인: guestbook
메서드: GET
배포 서버 실행 확인: 미확인
엔드포인트: /api/guestbook/{id}
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.2 · 초안 · 백엔드 구현 전 · 배포 미확인 · Android 연동 미확인.

방명록 한 건의 상세를 반환합니다. 모든 방명록은 전체 공개이므로 인증된 사용자는 누구의 기록이든 조회할 수 있습니다.

`GET /api/guestbook/{id}`

### 요청(Request)

| 요청 종류 | 필드 이름 | 필수 여부 | 타입 | 설명 |
| --- | --- | --- | --- | --- |
| Header | Authorization | ✅ | String | Bearer WATTAGAM_ACCESS_TOKEN — 카카오 토큰이 아닌 서비스 JWT |
| Path | id | ✅ | Long | 조회할 방명록의 양수 ID |

### PathVariable

```json
{"id": 101}
```

### RequestBody

```
해당 없음
```

### QueryParam

```
해당 없음
```

#### 응답 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| result.entryId / placeId / placeName | Long / Long / String | 방명록·장소 식별 및 장소명 |
| result.nickname | String | 작성자의 현재 닉네임 |
| result.imageUrl | String | 이미지 조회 경로. JWT 필요 |
| result.message | String 또는 null | 메시지 |
| result.createdAt / updatedAt | String | 작성 / 마지막 수정 시각(UTC ISO 8601) |
| result.edited | Boolean | 수정 여부 |
| result.mine | Boolean | 현재 사용자의 기록이면 true. 수정·삭제 버튼 노출 기준 |

### 연동 시 주의사항

- 타인의 기록에는 수정·삭제·신고 기능이 없습니다. mine=false이면 해당 버튼을 숨깁니다.
- 삭제된 방명록은 GUESTBOOK_404_1입니다.
