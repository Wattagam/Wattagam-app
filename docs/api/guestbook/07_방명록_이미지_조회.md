# [Wattagam] 방명록 이미지 조회

상태: API 개발 전
도메인: guestbook
메서드: GET
배포 서버 실행 확인: 미확인
엔드포인트: /api/guestbook/{id}/image
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.2 · 초안 · 백엔드 구현 전 · 배포 미확인 · Android 연동 미확인.

방명록 이미지를 JPEG 바이트로 반환합니다. OCI 주소나 임시 URL을 노출하지 않고, 서비스 JWT 확인 후 서버가 저장소에서 읽어 응답합니다. 방명록 응답의 `imageUrl`이 이 경로입니다.

`GET /api/guestbook/{id}/image`

### 요청(Request)

| 요청 종류 | 필드 이름 | 필수 여부 | 타입 | 설명 |
| --- | --- | --- | --- | --- |
| Header | Authorization | ✅ | String | Bearer WATTAGAM_ACCESS_TOKEN — 카카오 토큰이 아닌 서비스 JWT |
| Path | id | ✅ | Long | 이미지를 조회할 방명록의 양수 ID |

### PathVariable


### 응답(Response)

- 200 OK — 이미지 바이트
    
    ```json

    Cache-Control: private, no-store
    
    (JPEG 바이너리, JSON 본문 없음)
    ```

### 연동 시 주의사항

- 성공 응답은 공통 envelope가 아니라 이미지 본문입니다. 실패 응답만 JSON envelope입니다.
- Android는 이미지 로더(Coil 등)에 `Authorization` 헤더를 붙여야 합니다. 키를 인자로 받는 공개 이미지 API는 제공하지 않습니다.
- 저장소에 객체가 없으면(`read`가 null) GUESTBOOK_404_1로 응답합니다.
- `private, no-store`이므로 앱 쪽 캐시 정책은 Android 담당과 맞춥니다.
