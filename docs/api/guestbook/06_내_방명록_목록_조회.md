# [Wattagam] 내 방명록 목록 조회

상태: API 개발 전
도메인: guestbook
메서드: GET
배포 서버 실행 확인: 미확인
엔드포인트: /api/me/guestbook
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.2 · 초안 · 백엔드 구현 전 · 배포 미확인 · Android 연동 미확인.

현재 사용자가 작성한 방명록을 최신순으로 반환합니다. 마이페이지의 '내 추억' 목록에 사용합니다.

`GET /api/me/guestbook`

### 요청(Request)

| 요청 종류 | 필드 이름 | 필수 여부 | 타입 | 설명 |
| --- | --- | --- | --- | --- |
| Header | Authorization | ✅ | String | Bearer WATTAGAM_ACCESS_TOKEN — 카카오 토큰이 아닌 서비스 JWT |
| Query | page |  | Integer | 0부터 시작. 기본값 0 |
| Query | size |  | Integer | 1–50. 기본값 20 |

### PathVariable

```
해당 없음
```

### RequestBody

```
해당 없음
```

### QueryParam

```json
{
  "page": 0,
  "size": 20
}
```

### 응답(Response)

- 200 OK — 내 방명록 목록
    
    ```json
    {
      "isSuccess": true,
      "status": 200,
      "code": "GUESTBOOK_200_6",
      "message": "내 방명록을 조회했습니다.",
      "result": {
        "entries": [
          {
            "entryId": 101,
            "placeId": 1,
            "placeName": "310관",
            "imageUrl": "/api/guestbook/101/image",
            "message": "오늘도 여기 왔다감!",
            "createdAt": "2026-11-06T08:00:00Z",
            "edited": false
          }
        ],
        "page": 0,
        "size": 20,
        "hasNext": false
      },
      "timeStamp": "2026-11-06T09:00:00Z"
    }
    ```
    

#### 응답 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| result.entries | Array | createdAt DESC, entryId DESC 순. 없으면 빈 배열 |
| entries[].entryId / placeId / placeName | Long / Long / String | 방명록·장소 식별 및 장소명 |
| entries[].imageUrl / message | String / String 또는 null | 이미지 조회 경로 / 메시지 |
| entries[].createdAt / edited | String / Boolean | 작성 시각 / 수정 여부 |
| result.page / size / hasNext | Integer / Integer / Boolean | 요청 페이지 / 크기 / 다음 페이지 여부 |

### 연동 시 주의사항

- '작성 중' 초안은 기기에 저장되므로 이 API에 포함되지 않습니다.
- 도장 보유 여부는 `GET /api/me/stamps`로 조회합니다.

### 근거

PRD v1.2, ERD, 태영님 구현(develop)의 공통 응답·위치 검증·도장 지급·이미지 저장소 계약을 기준으로 한 초안입니다. 구현 후 로컬 검증 결과로 갱신합니다.
