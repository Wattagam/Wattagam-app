# [Wattagam] 장소별 갤러리 조회

상태: API 개발 전
도메인: guestbook
메서드: GET
배포 서버 실행 확인: 미확인
엔드포인트: /api/places/{id}/guestbook
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.2 · 초안 · 백엔드 구현 전 · 배포 미확인 · Android 연동 미확인.

선택한 장소의 모든 공개 방명록을 최신순으로 반환합니다. 페이지 단위로 조회합니다.

`GET /api/places/{id}/guestbook`

### 요청(Request)

| 요청 종류 | 필드 이름 | 필수 여부 | 타입 | 설명 |
| --- | --- | --- | --- | --- |
| Header | Authorization | ✅ | String | Bearer WATTAGAM_ACCESS_TOKEN — 카카오 토큰이 아닌 서비스 JWT |
| Path | id | ✅ | Long | 조회할 장소의 양수 ID |
| Query | page |  | Integer | 0부터 시작. 기본값 0 |
| Query | size |  | Integer | 1–50. 기본값 20 |

### PathVariable

```json
{"id": 1}
```

### RequestBody

```
해당 없음
```

### QueryParam

```json
{
  "page": 0,
  "size": 20
}
```

#### 응답 필드

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| result.entries | Array | createdAt DESC, entryId DESC 순. 없으면 빈 배열 |
| entries[].entryId | Long | 방명록 ID |
| entries[].nickname | String | 작성자의 현재 닉네임 |
| entries[].imageUrl | String | 이미지 조회 경로. JWT 필요 |
| entries[].message | String 또는 null | 메시지 |
| entries[].createdAt | String | 작성 시각(UTC ISO 8601) |
| entries[].edited | Boolean | updatedAt이 createdAt보다 늦으면 true. '수정됨' 표시용 |
| entries[].mine | Boolean | 현재 사용자가 작성한 기록인지 |
| result.page / size / hasNext | Integer / Integer / Boolean | 요청 페이지 / 크기 / 다음 페이지 여부 |

### 연동 시 주의사항

- 방명록이 없는 장소는 200과 빈 entries를 반환합니다. 404는 장소가 없을 때만 씁니다.
- 닉네임 변경이 과거 방명록 표시명에 반영되는지는 PRD 미정 항목입니다. 현재는 조회 시점의 닉네임을 보여주는 것으로 가정합니다.
- 이미지 주소는 인증이 필요한 경로입니다. Android는 서비스 JWT 헤더를 붙여 이미지를 요청해야 합니다. 목록용 축소 이미지는 제공하지 않습니다.

PRD v1.2, ERD, 태영님 구현(develop)의 공통 응답·위치 검증·도장 지급·이미지 저장소 계약을 기준으로 한 초안입니다. 구현 후 로컬 검증 결과로 갱신합니다.
