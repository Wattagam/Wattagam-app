# [Wattagam] 방명록 작성 (도장 지급 포함)

상태: 백엔드 구현 완료 (로컬 통합 테스트 통과)
도메인: guestbook
메서드: POST
배포 서버 실행 확인: 미확인
엔드포인트: /api/places/{id}/guestbook
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.3 · 백엔드 구현 완료(로컬 통합 테스트 통과) · 배포 미확인 · Android 연동 미확인.

선택한 장소에 사진과 메시지를 남깁니다. 서버가 현재 GPS를 다시 검증하고, 통과하면 이미지를 OCI Object Storage에 저장한 뒤 방명록 저장과 최초 도장 지급을 한 DB 트랜잭션으로 처리합니다. 모든 방명록은 전체 공개입니다. 이미지 업로드는 별도 API 없이 이 요청에 포함합니다.

`POST /api/places/{id}/guestbook`

### 요청(Request)

| 요청 종류 | 필드 이름 | 필수 여부 | 타입 | 설명 |
| --- | --- | --- | --- | --- |
| Header | Authorization | ✅ | String | Bearer WATTAGAM_ACCESS_TOKEN — 카카오 토큰이 아닌 서비스 JWT |
| Header | Content-Type | ✅ | String | multipart/form-data |
| Path | id | ✅ | Long | 방명록을 남길 장소의 양수 ID |
| Part | image | ✅ | File | Android가 합성한 JPEG 한 장. image/jpeg, 최대 5 MiB, 가로·세로 각 최대 4,096px |
| Part | message |  | String | 선택 메시지. 0–80자 |
| Part | latitude | ✅ | Number | 현재 위도, -90 이상 90 이하 |
| Part | longitude | ✅ | Number | 현재 경도, -180 이상 180 이하 |
| Part | accuracyMeters | ✅ | Number | 위치 측정 정확도(m). 0 이상, 20m 초과는 거절 |
| Part | measuredAt | ✅ | String | 위치를 측정한 UTC ISO 8601 시각. 측정 후 60초 이내여야 함 |
| Part | clientRequestId | ✅ | String | 재시도 중복 방지 키(UUID). 최대 64자 |

### 연동 시 주의사항

- 처리 순서: ① `UserRepository.findByIdForUpdate(userId)`로 사용자 행 잠금(탈퇴와 같은 락) → ② 작성 권한·`clientRequestId` 중복 확인 → ③ `LocationValidationService.validate`로 GPS 재검증 → ④ `GuestbookImageStorage.createKey()`/`put()`으로 이미지 저장 → ⑤ 방명록 저장 + `StampService.grantForPublishedEntry` 호출(같은 트랜잭션).
- 위치 조건 불충족은 GUESTBOOK_403_1(OUTSIDE_RADIUS) / _2(LOW_ACCURACY) / _3(STALE_LOCATION)로 구분합니다. 좌표 범위·시각 형식 오류와 미래 시각은 방문 확인 API와 같이 COMMON_400_2입니다. 과거 방문 확인 결과를 작성 권한으로 재사용하지 않습니다.
- 이미지 형식(JPEG 아님)·용량·해상도 오류는 저장 모듈이 COMMON_400_2로 거절합니다. `put`이 이미 있는 키(412)로 false를 반환하면 기존 객체를 보존하고 새 키를 만들어 다시 저장합니다.
- DB에는 `image_object_key`만 저장하고 응답·로그에 OCI 주소나 키를 노출하지 않습니다. 업로드 응답을 받지 못해도 객체가 남았을 수 있으므로 시도한 키는 정리 재시도에 쓸 수 있게 보존합니다. 이미지 저장 후 방명록·도장 저장이 실패하면 이번 요청의 이미지를 삭제합니다.
- clientRequestId는 사용자별로 유일합니다. 같은 값으로 재시도하면 새로 저장하지 않고 기존 결과를 200으로 반환합니다(도장은 추가되지 않으므로 stampAwarded=false). 네트워크 재시도에는 같은 값을, 새 작성에는 새 UUID를 사용합니다.
- 저장소 통신·권한 오류는 GUESTBOOK_503_1이며 방명록과 도장은 만들어지지 않습니다. Android는 실패 시 초안을 지우지 않고, 재시도 때 위치를 다시 측정합니다.
- 같은 `clientRequestId`를 다른 장소(`id`)로 재사용하면 기존 방명록을 돌려주지 않고 COMMON_400_2로 거절합니다.
- `message`가 빈 문자열이면 null로 저장합니다. 길이는 문자(코드 포인트) 수 기준이며, 공백만 있는 메시지는 그대로 저장합니다.
- 이미지 파트는 비어 있으면 COMMON_400_2입니다. 업로드 크기 제한(이미지 5 MiB, 요청 전체 6 MB)을 넘기면 COMMON_400_2입니다.
- OCI 이미지 저장소가 꺼진 환경(로컬 기본값)에서는 GUESTBOOK_503_1을 반환합니다.
- 업로드 응답을 받지 못한 모호한 실패에서는 같은 요청 안에서 삭제를 시도하되 DB가 그 키를 참조하지 않을 때만 지웁니다. 삭제까지 실패하면 객체가 남을 수 있으며, 별도 정리 작업은 MVP에 포함하지 않습니다.
- `GUESTBOOK_*` 코드는 `ErrorCode`에 추가됐습니다.
