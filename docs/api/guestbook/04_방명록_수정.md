# [Wattagam] 방명록 수정

상태: 백엔드 구현 완료 (로컬 통합 테스트 통과)
도메인: guestbook
메서드: PATCH
배포 서버 실행 확인: 미확인
엔드포인트: /api/guestbook/{id}
담당 BE: 이시형
프론트 구현 여부: 시작 전

### API 설명

명세 v0.3 · 백엔드 구현 완료(로컬 통합 테스트 통과) · 배포 미확인 · Android 연동 미확인.

본인이 작성한 방명록의 메시지를 수정합니다. 이미지와 장소는 수정할 수 없고, 수정으로 도장이 추가되지 않습니다.

`PATCH /api/guestbook/{id}`

### 요청(Request)

| 요청 종류 | 필드 이름 | 필수 여부 | 타입 | 설명 |
| --- | --- | --- | --- | --- |
| Header | Authorization | ✅ | String | Bearer WATTAGAM_ACCESS_TOKEN — 카카오 토큰이 아닌 서비스 JWT |
| Header | Content-Type | ✅ | String | application/json |
| Path | id | ✅ | Long | 수정할 방명록의 양수 ID |
| Body | message | ✅ | String 또는 null | 0–80자. 빈 문자열 또는 null이면 메시지를 지움 |

### PathVariable

```json
{"id": 101}
```

### RequestBody

```json
{
  "message": "메시지를 수정했어요"
}
```

### QueryParam

```
해당 없음
```

### 연동 시 주의사항

- message 필드가 없으면 COMMON_400_2입니다. 지우려면 null 또는 빈 문자열을 보냅니다.
- 타인의 기록은 COMMON_403_1로 거절하고 데이터를 바꾸지 않습니다.
- 이미지 교체는 MVP에서 제외합니다. 이미지를 바꾸려면 삭제 후 다시 작성합니다. (backend README의 '수정은 새 키로 저장' 규칙은 이미지 교체를 넣기로 정할 때 적용)
- 메시지 길이는 문자(코드 포인트) 수 기준 80자이며, 빈 문자열은 null로 저장합니다. 수정하면 `updatedAt`이 갱신되어 `edited=true`입니다. 이미지·도장은 바뀌지 않습니다.
- 본문이 JSON이 아니거나 `message`가 문자열·null이 아니면 COMMON_400_2입니다.
